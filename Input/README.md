# Input

Tu wrzucasz pliki PDF do konwersji (pojedynczy plik lub kilka naraz —
program obsługuje też cały folder w trybie wsadowym).

`przyklad.pdf` to syntetyczny plik testowy: 3 strony tabeli bez linii
siatki, z powtarzającym się nagłówkiem i stopką — pokazuje przypadek,
który program ma rozpoznawać (wiersze rozdzielone niewielkim odstępem,
bez linii tabeli).
